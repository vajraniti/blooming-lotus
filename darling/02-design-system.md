# 02 — дизайн-система

Все значения взяты из живого сайта (`assets/css/main.css`). Если сомневаешься —
открой его, он главный источник.

## Цвета

```css
--ink:    #060606;  /* фон, почти чёрный, не #000 */
--bone:   #e9e5dc;  /* основной текст, тёплый костяной, не #fff */
--bone-2: #c9c5bc;  /* текст абзацев */
--ash:    #8a8780;  /* подписи, неактивное меню */
--ash-2:  #5f5d58;  /* совсем второстепенное */
--slab:   #1f1e1b;  /* заливка полей и кнопок */
--slab-2: #2b2a26;  /* hover / focus у полей и кнопок */
--wire:   #3b3a35;  /* линии — ТОЛЬКО в схеме раунда, битовой полосе и цепочке меню */
--relic:  #d3145a;  /* единственный акцент: маджента-кровь */
```

- Акцент `--relic` редко и по делу: активный крестик в меню, ошибки, подключи в схеме,
  подсветка битов, «нет» в списке ересей. Не на кнопках, не на заголовках, не на ссылках.
- Цветное фото допускается одно-два на страницу (красный диван, красная надпись) —
  это и есть второй «акцент», больше не надо.
- Тени, градиенты, свечения, стекло — нет.

## Шрифты и роли

| Роль | Шрифт | Как |
|---|---|---|
| Текст | Cormorant Garamond 500 | `20px/1.55`, `liga kern onum` (старостильные цифры) |
| Заголовки секций | Cormorant Garamond 300, капс | `clamp(68px, 7.6vw, 138px)/.86` — огромно и тонко |
| Лид | Cormorant 500 | `1.32em/1.42` |
| Буквица | UnifrakturMaguntia | `5.1em/.78`, float left |
| Номера меню I…IX | UnifrakturMaguntia | `18px` |
| Названия пунктов меню | IBM Plex Mono | `11px`, `letter-spacing .14em`, капс — **только здесь** разрядка |
| Данные (hex, ключи, таблицы) | IBM Plex Mono 400/500 | 13–26px, `letter-spacing .04–.08em` |
| Мелкие подписи, хинты, кнопки | Arial | `13–16px`, цвет `--ash` — нарочно «вебовый», без стиля |

- Шрифты свои, в `assets/fonts/` (woff2, лицензии OFL рядом). Кириллица — отдельными
  файлами `*-cyrillic.woff2` через `unicode-range`. UnifrakturMaguntia кириллицы не
  имеет, поэтому им набраны только римские цифры и латинская буквица.
- Arial для подписей — сознательный приём «как у людей»: овертвайр-эффект, обычный
  системный шрифт рядом с красивой антиквой. Моноширинный — только для данных.

## Сетка и ритм

- Меню фиксировано слева, `--rail: 250px`, без панели и без границы: зерно идёт
  под ним так же, как под контентом, края нет.
- Поля контента: `--gut: clamp(48px, 6vw, 112px)`.
- `body { min-width: 1180px }` — сайт только для ПК, мобильную версию не делали.
- Отступы секций **разные**: базово `110px`, а у отдельных — 60, 130, 70, 150, 90.
  Одинаковые отступы = ИИ-ритм.
- Сетки внутри секций асимметричные: `1.25fr / .75fr`, `.66fr / 1.34fr`, `.8fr / 1.2fr`.
  Фото по ширине «как получилось»: 88%, 48%, 64%, 60%, со сдвигами `margin-top`.
- Где удобно — `position: sticky` у боковой колонки (схема раунда, фото в «Wounds»).

## Hero

- Сверху мелкая подпись Arial 14px (название + авторы, год).
- Три ч/б фото раскиданы коллажем, абсолютным позиционированием, разного размера:
  нимб справа (`right 7%, top 13%`, ~21vw), рука с чётками слева (`top 19%`, ~12vw),
  лицо за волосами по центру (`left 43%, top 25%`, ~8.5vw).
- Поверх — огромный логотип IDEA (SVG, ширина `min(78%, 1100px)`), прижат к низу.
- Справа «эхо»: фраза «can you read me?» четыре раза — после 0, 2, 5 и 8½ раундов
  шифра (байты как Latin-1). Arial `clamp(21px, 2.05vw, 30px)`, цвет `#8d8b86`.
  При загрузке один раз пробегает hex-скремблом.

## Меню (любимое — не трогать)

- Логотип сверху, 150px.
- Список с отступом, слева пунктирная «цепочка»: 1px, `repeating-linear-gradient`
  `--wire 0 3px, transparent 3px 6px`.
- У каждого пункта «бусина»: кружок 7px, заливка `--ink`, обводка `--wire`.
  Hover — обводка `--bone`.
- Активный пункт: бусина превращается в **красный крестик** 9×13 через `clip-path`.
- Строка пункта: grid `66px 1fr` — готическая цифра + моно-капс название.
- При наведении название пробегает hex-цифрами и встаёт на место (380 мс).
- Внизу меню: `en / ru` и `grain: on/off` — подчёркнутые текстовые кнопки Arial 13px.

## Компоненты

- **Поля ввода**: без рамки, заливка `--slab`, фокус — `--slab-2`, для клавиатуры
  `:focus-visible { outline: 1px solid var(--bone-2); outline-offset: 2px }`.
  Ошибка — красная полоска слева `box-shadow: inset 3px 0 0 var(--relic)`.
- **Кнопки**: заливка `--slab-2`, hover — инверсия в `--bone` на `--ink`. «Призрачные»
  кнопки — просто подчёркнутый текст.
- **Сегмент-переключатель**: кнопки впритык с `gap: 2px`, активная инвертирована.
- **Табы раундов**: Cormorant 21px, активный — подчёркнут, без плашки.
- **Таблицы**: без линеек, `row-gap: 2px`, подписи строк серифом цветом `--ash`.
- **Зона сброса файла**: просто прямоугольник `--slab` 210px с крестиком и крупной
  серифной надписью; при перетаскивании крестик краснеет.
- **Прогресс**: полоска 2px цвета `--bone`, без фона-дорожки.
- **Ссылки**: подчёркнуты, `thickness 1px`, `offset 3px`, цвет текста.

## Движение (всё, что осталось)

- Зерно: **статичный** тайл шума 220×220, нарисованный канвасом, `opacity .055`,
  `z-index 0` под контентом. Не анимируется. Выключатель в меню, состояние в
  `localStorage` (`idea-grain`).
- Скрамбл hex-цифрами (`FX.scramble` в `assets/js/fx.js`): эхо в hero один раз при
  загрузке (900 мс, строки с шагом 380 мс), значения в схеме раунда при смене таба
  (260 мс), пункты меню на hover (380 мс). При `prefers-reduced-motion` — сразу
  итоговый текст.
- Переходы цвета `.15–.25s`. Больше ничего: ни появления при скролле, ни параллакса.

## Картинки

- Все фото ч/б: в CSS `filter: grayscale(1) contrast(1.06) brightness(.92)`,
  плюс заранее переведены в серый с контрастом ×1.08 (`tools/prep_photos.py`).
- Цветные — только с классом `.relic.color` (`contrast(1.04) brightness(.9)`).
- Приём «выборочный цвет»: всё в серый, кроме насыщенного маджента/малинового
  (HSV: `s > .55`, `v > .35`, `h > .88 или h < .02`). Так был сделан первый портрет.
- Фото без рамок, без подписей «fig. N», без скруглений. Просто картинка в потоке
  или в коллаже, неровного размера.
- ECB-демо: нимб-ангел 256×256, постеризован до трёх тонов (0 / 128 / 255),
  лежит в `assets/js/angel-data.js` как base64 — чтобы канвас не «заражался» на file://.

## Логотип-леттеринг

- Буквы — контуры Cormorant Garamond Bold (через fontTools), к ним вручную
  дорисованы: лезвия из засечек I, шип на чаше D, игла из средней перекладины E,
  игла через вершину A и хвост из правой ноги, большая дуга-росчерк из головы I
  над D и E в иглу A, капля в просвете D, три звезды-искры (4 луча).
- Всё одним `<symbol>` в спрайте, цвет `currentColor`, используется в hero и в меню.
- Генератор: `tools/lettering.py`. Для другого слова — переставить координаты
  украшений под новые буквы, логика та же.
- Важно: украшения тонкие и кривые, разной толщины по длине (переменная ширина
  штриха), а не ровные линии. Ровно — значит ИИ.

## Язык

- Английский — в разметке, русский — словарь `assets/js/i18n-ru.js`, ключи —
  сам английский текст (как в gettext), в HTML только голый атрибут `data-i18n`.
- Строки из JS — `I18N.L('english', 'русский')`, множественное число — `I18N.plural`,
  ошибки из Rust переводятся регулярками в `I18N.err`.
- Выбор хранится в `localStorage` (`idea-lang`), по умолчанию — язык браузера.
