сайте — обработанные версии этих же картинок (серый, контраст, кроп).

## layout/ — как раскладывать

- `goth-styling-site.webp` — сайт-образец: огромный тонкий серифный капс, фото
  раскиданы неровно и заходят под буквы, мелкие подписи, много чёрного. Отсюда
  hero-коллаж и размер заголовков секций.

- **REMORSE** — надпись BleachFX, главный референс леттеринга. Картинку не копировал:
  у автора стоит «Do not reuse without permission». Смотреть по ссылке:
  https://x.com/BleachFX/status/1764682485894459807
  Что взято: обычные засечные капсы, из которых растут шипы, иглы и хвосты переменной
  толщины, длинная дуга-росчерк через всё слово, звёздочки-искры по краям.

  Пример человеческой простоты без лоска.

  аккаунте, сюда не копировал.
